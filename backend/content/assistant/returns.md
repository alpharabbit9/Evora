## Returns and exchanges

The store's returns policy has not been decided yet. The home page mentions returns within 30 days
of delivery, but that window is not a confirmed policy, and there is no self-service returns request.
Eligibility for returns and exchanges, including for cash-on-delivery orders, will be published on
the shipping and returns page once it is decided. For a problem with an order, contact the store's
support email.
